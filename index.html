About Meنبذة عني

Clean code. Thoughtful design.كود نظيف. تصميم مدروس.

I'm Abdulrhman Alaa Nassar — a web developer focused on turning ideas into fast, accessible and responsive websites that people can use on any screen. أنا عبدالرحمن علاء نصار — مطوّر ويب أحوّل الأفكار إلى مواقع سريعة وسهلة الوصول ومتجاوبة تعمل على أي شاشة.

I believe a good website is not only visually appealing — it should load fast, feel natural on every screen and be readable by everyone. أعتقد أن الموقع الجيد ليس جميلاً فحسب — بل يجب أن يُحمَّل بسرعة، وأن يكون طبيعياً على كل الشاشات، وأن يكون مقروءاً من الجميع.

My work combines semantic HTML5, modern CSS3 and JavaScript on the front end with Python and Flask on the back end, versioned with Git and hosted through GitHub. Every project is built to be easy to maintain and simple to extend. يجمع عملي بين HTML5 الدلالي وCSS3 الحديث وJavaScript في الواجهة الأمامية، مع Python وFlask في الخلفية، وإدارة الإصدارات عبر Git والاستضافة على GitHub. كل مشروع مبني ليكون سهل الصيانة والتوسعة.

I care about clean, maintainable code and smooth details, and I am always open to new freelance projects. أهتم بالكود النظيف القابل للصيانة وبالتفاصيل السلسة، وأنا منفتح دائماً على مشاريع العمل الحر الجديدة.
